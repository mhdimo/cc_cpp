The port and the reference

The memory a session takes and the CPU it burns, measured the same way for the native port and for the bundle of JavaScript the reference runs on.

session memory (MB) the start (ms) the start (CPU ms) the idling (CPU ms/s)
the reference (claude)193.19911012.5
the port (cc++)26.162401.6
Measured with python3 scripts/bench.py on macOS. The memory is the resident memory of the process and of every child it has. The CPU of the start is the whole process, its threads included: the port starts a pool of threads and reaches the screen in less time, though the threads cost more CPU together.
